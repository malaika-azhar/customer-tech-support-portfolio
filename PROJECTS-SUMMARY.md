# 📊 Customer Support Portfolio — Executive Summary

## 🎯 Purpose
This portfolio demonstrates customer technical support capabilities through structured documentation, ticket management, escalation procedures, and knowledge base creation — modeled on real IT help-desk workflows.

---

## 📋 Project Breakdown

### 01 — Video Knowledge Base 🎥
Screen-recording scripts for common IT issues, written so they can be read aloud while demonstrating the fix on screen. Each script includes a visual Mermaid decision path.

| Topic | Issue | Resolution | Time to Resolution |
|---|---|---|---|
| DNS Resolution | "Server not found" | Flush DNS, set fallback DNS server | 3 min |
| Email Sending | "SMTP server not responding" | Correct port to 587, enable auth | 3 min |
| VPN Connection | "Authentication failed" | Unlock account, sync credentials | 2 min |
| Printer Offline | "Printer not responding" | Restart spooler, update driver | 3 min |
| WiFi Connectivity | "No internet access" | Release/renew IP, flush DNS | 2 min |
