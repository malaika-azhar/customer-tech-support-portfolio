## 📝 Escalation Structure
| Section | Description |
|---|---|
| Situation | What the customer reported and what's already ruled out |
| Diagnostics Performed | Everything tried before escalating |
| Escalated To | Which team/role and why |
| Handoff Notes | What the receiving team needs to know |
| Outcome | Result after escalation |
