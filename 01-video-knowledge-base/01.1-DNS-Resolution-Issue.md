# Video Script: DNS Resolution Issue ("Server Not Found")

**Format:** Screen-recording script (Loom/Zoom)
**Customer sees:** "This site can't be reached" / "Server not found"

---

**[0:00]** "Hi! This is a quick walkthrough for the 'server not found' error you've been seeing. It usually happens because your computer has an outdated address saved for the website — think of it like an old contact number that's no longer in service."

**[0:20]** *(Open Command Prompt)* "First, let's clear that saved information. I'll type `ipconfig /flushdns` and press Enter."

**[0:45]** "You should see a message saying the cache was flushed successfully."

**[1:00]** *(Switch to browser)* "Now let's do a hard refresh — hold Ctrl and press F5. This tells the browser to fetch a completely fresh copy of the page."

**[1:20]** "And there it is — the site loads normally now."

**[1:35]** "If this happens again, changing your DNS server to a public one like Google's (8.8.8.8) can also help — I've left those steps in the ticket notes just in case."

**Resolution:** Flush DNS, change DNS server if needed
