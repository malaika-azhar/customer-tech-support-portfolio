# Video Script: Email Sending Failure ("SMTP Server Not Responding")

**Format:** Screen-recording script (Loom/Zoom)
**Customer sees:** "SMTP server not responding" / emails stuck in outbox

---

**[0:00]** "Hi — this is about the emails getting stuck and showing an SMTP error. This usually comes down to two things: the port your email client is using, or an authentication setting that needs to be turned on."

**[0:20]** *(Open email client settings)* "Let's check the outgoing server port first — it should be 587 for most providers, with TLS encryption enabled."

**[0:45]** "Next, let's make sure 'My outgoing server requires authentication' is checked — this is a common one that gets missed."

**[1:10]** "Let's save these settings and send a test email..."

**[1:30]** "And it went through. That confirms it was the port/authentication setting."

**[1:45]** "If you ever switch email providers or set this up on a new device, just remember: correct port + authentication enabled — that's usually the fix."

**Resolution:** Check ports, enable authentication
