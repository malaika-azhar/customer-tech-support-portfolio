# Video Script: Printer Offline ("Printer Not Responding")

**Format:** Screen-recording script (Loom/Zoom)
**Customer sees:** Printer shows as "Offline" or "Not responding"

---

**[0:00]** "Hi — this is about the printer showing offline. Nine times out of ten, this is fixed by restarting a background service called the Print Spooler, so let's start there."

**[0:15]** *(Open Services)* "I'll open the Services app, find 'Print Spooler,' right-click, and select Restart."

**[0:40]** "Let's check the printer status now... still offline. That means we need one more step — updating the printer driver."

**[1:00]** *(Device Manager)* "I'll open Device Manager, find the printer under 'Print queues,' right-click, and select 'Update driver.'"

**[1:30]** "Let's send a test print now..."

**[1:45]** "Printing normally. So the two things worth remembering: restart the spooler first, and if that doesn't work, update the driver next."

**Resolution:** Restart spooler, update driver
