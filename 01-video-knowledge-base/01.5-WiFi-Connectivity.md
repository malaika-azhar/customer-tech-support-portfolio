# Video Script: WiFi Connectivity Issue ("No Internet Access")

**Format:** Screen-recording script (Loom/Zoom)
**Customer sees:** Connected to WiFi but "No internet access"

---

**[0:00]** "Hi — you're connected to WiFi but there's no actual internet access, which usually means your device has a bad or stuck IP address. Let's fix that."

**[0:15]** *(Open Command Prompt)* "I'll type `ipconfig /release`, then `ipconfig /renew`. This drops the current address and requests a fresh one from the router."

**[0:45]** "Let's also flush the DNS cache while we're here — `ipconfig /flushdns`."

**[1:05]** *(Check browser)* "Let's test a website now..."

**[1:20]** "And we're online. If this happens often on the same network, it's worth asking whoever manages that WiFi to check their router — but for a one-off, this release/renew trick almost always does it."

**Resolution:** Release/renew IP, flush DNS
