# Troubleshooting Flowchart: Printer Offline

## Mermaid Code
Copy-paste this into [draw.io](https://draw.io) or [Mermaid Live](https://mermaid.live/):

```mermaid
flowchart TD
    Start([Printer Offline?]) --> A{Powered & network-connected?}
    A -->|No| B[Power cycle printer]
    B --> End1([Issue Resolved ✅])
    A -->|Yes| C[Restart Print Spooler service]
    C --> D{Online now?}
    D -->|Yes| End2([Issue Resolved ✅])
    D -->|No| E{Stuck jobs in queue?}
    E -->|Yes| F[Clear print queue]
    F --> D
    E -->|No| G{Driver matches firmware?}
    G -->|No| H[Update printer driver]
    H --> End3([Issue Resolved ✅])
    G -->|Yes| I{IP changed recently?}
    I -->|Yes| J[Update port IP configuration]
    J --> End4([Issue Resolved ✅])
    I -->|No| End5([Escalate to Systems Team])
```

## Decision Tree (Text Version)
```
Printer Offline?
├─ Powered & network-connected?
│  └─ No → Power cycle printer
├─ Restart Print Spooler service
│  ├─ Online now → Issue Resolved ✅
│  └─ Still offline
│     ├─ Stuck jobs in queue → Clear queue → Recheck
│     └─ No stuck jobs
│        ├─ Driver/firmware mismatch → Update driver → Issue Resolved ✅
│        └─ Driver OK
│           ├─ IP changed recently → Update port config → Issue Resolved ✅
│           └─ No known cause → Escalate to Systems Team
```
