# Troubleshooting Flowchart: WiFi Not Working

## Mermaid Code
Copy-paste this into [draw.io](https://draw.io) or [Mermaid Live](https://mermaid.live/):

```mermaid
flowchart TD
    Start([WiFi Not Working?]) --> A[Check WiFi ON/OFF]

    A -->|OFF| B[Enable WiFi]
    B --> End1([Issue Resolved ✅])

    A -->|ON| C[Check Network List]

    C -->|Network Not Found| D[Check Router/SSID Broadcasting]
    D --> E[Router Power Cycle]
    E --> End2([Issue Resolved ✅])

    C -->|Network Found| F[Enter Password]
    F --> G{Connected?}

    G -->|No| H[Check Password & Caps Lock]
    H --> F

    G -->|Yes| I[Check Internet Access]

    I -->|No Internet| J["ipconfig /all"]
    J --> K{IP Address?}

    K -->|169.254.x.x APIPA| L["ipconfig /release & /renew"]
    L --> M{DHCP Success?}
    M -->|No| N[Check DHCP Server]
    M -->|Yes| O[Check DNS]

    K -->|Valid IP| P["ipconfig /flushdns"]
    P --> O

    O --> Q{Ping 8.8.8.8?}
    Q -->|Success| R[Ping google.com]
    R --> S{Success?}
    S -->|Yes| End3([Issue Resolved ✅])
    S -->|No| T[Check DNS Server]
    T --> End4([Escalate to Network Team])

    Q -->|Failed| U[Check Firewall/Router]
    U --> End5([Escalate to Network Team])
```

## Decision Tree (Text Version)
```
WiFi Not Working?
├─ WiFi ON/OFF?
│  └─ OFF → Enable WiFi
├─ Network visible in list?
│  ├─ No → Check router/SSID broadcasting → Power cycle router
│  └─ Yes → Enter password
│     └─ Connected?
│        ├─ No → Check password/Caps Lock → Retry
│        └─ Yes → Check internet access
│           ├─ No internet → ipconfig /all
│           │  ├─ APIPA (169.254.x.x) → release/renew → Check DHCP server if fails
│           │  └─ Valid IP → flush DNS → Check DNS resolution
│           │     └─ Ping 8.8.8.8 fails → Check firewall/router → Escalate
│           │     └─ Ping succeeds, google.com fails → Check DNS server → Escalate
│           └─ Internet works → Issue Resolved ✅
```
