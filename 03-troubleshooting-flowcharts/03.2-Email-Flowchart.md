# Troubleshooting Flowchart: Email Not Sending

## Mermaid Code
Copy-paste this into [draw.io](https://draw.io) or [Mermaid Live](https://mermaid.live/):

```mermaid
flowchart TD
    Start([Email Not Sending?]) --> A{Receiving mail OK?}
    A -->|No| B([Escalate — account/network issue])
    A -->|Yes| C[Check outgoing SMTP port]
    C -->|Port 25| D[Try port 587 with TLS]
    C -->|Already 587| E[Check authentication setting]
    D --> E
    E -->|Disabled| F[Enable outgoing authentication]
    E -->|Enabled| G[Test port connectivity via telnet]
    F --> G
    G -->|Blocked| H[Check firewall settings]
    G -->|Open| I[Send test email]
    H --> End1([Escalate to Network Team])
    I -->|Delivered| End2([Issue Resolved ✅])
    I -->|Fails| End3([Escalate to Email Platform Support])
```

## Decision Tree (Text Version)
```
Email Not Sending?
├─ Receiving mail OK?
│  └─ No → Escalate (account/network issue)
├─ Outgoing port check
│  ├─ Port 25 → Switch to 587 with TLS
│  └─ Port 587 already → Check authentication
├─ Authentication enabled?
│  ├─ No → Enable "requires authentication"
│  └─ Yes → Test port connectivity (telnet)
├─ Port blocked? → Check firewall → Escalate to Network Team
└─ Port open → Send test email
   ├─ Delivered → Issue Resolved ✅
   └─ Still failing → Escalate to Email Platform Support
```
