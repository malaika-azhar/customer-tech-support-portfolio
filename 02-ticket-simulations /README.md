## 📝 Ticket Structure
| Section | Description |
|---|---|
| Ticket Details | ID, priority, category, status, resolution time |
| Customer Report | The issue as the customer described it |
| Diagnostic Steps | Numbered troubleshooting actions taken |
| Resolution | The fix applied |
| Root Cause Analysis | Why it happened |
| Follow-Up | Preventive recommendation |
